# Sobre Esta Tarea
La tarea consistía en crear un simulador y planificador dieciochero, que tuviera un manejo de SIGINT (ctrl+C), aislamiento de errores, control de concurrencia, manejo de dependencias y comunicación entre procesos utilizando pipes, sin utilizar hilos (threads) ni mecanismos de sincronización de. Además, el planificador debía estar armado para aguantar altas cargas de trabajo, siendo sometido a pruebas de estrés de hasta 10000 actividades. Mas detalles se explican dentro del `readme.md` de la tarea. 

## Listado De archivos:
 * Actividad: Contiene los archivos de enunciado y rubrica de la tarea 1
 * App: Contiene todos los archivos necesarios para correr y explicar como compilar la Actividad
 * Ideas.txt: Archivo Temporal donde juntamos las ideas y recomendaciones que recolectemos
